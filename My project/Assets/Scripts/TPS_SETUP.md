# TPS 세팅 가이드

New Input System + URP 기준. 아래 순서대로 에디터에서 연결하면 이동/조준/발사가 동작한다.

## 스크립트 목록
- `WeaponHolder.cs` — 총을 손 본(mixamorig:RightHand)에 부착
- `ThirdPersonCamera.cs` — 오버숄더 TPS 카메라(조준 시 줌인)
- `PlayerController.cs` — 카메라 기준 이동/회전/중력/점프
- `PlayerShooter.cs` — 레이캐스트 발사, 연사, 이펙트, 데미지 전달
- `TargetDummy.cs` — 발사 테스트용 표적(IDamageable)
- `BossController.cs` — 보스(AlienMonster) AI: 추격/할퀴기/돌진/레이저/강우/텔레포트/공중 처형
- `BossRig.cs` — 보스 팔·손 절차적 포즈(공격 클립 없이 팔을 직접 겨눔, 요청값을 보간해 부드럽게 적용)
- `BossFx.cs` — 보스 이펙트(충전 구체/레이저 광선/돌진 통로 예고/텔레포트 섬광/발톱 궤적·자국)
- `BossClone.cs` — 분신 처형 패턴의 분신(보스 모델 복제 껍데기, 피해를 받지 않는 표적)
- `BossMeteor.cs` — 하늘에서 떨어지는 낙하물(레이저 강우 / 구체) / `BossOrb.cs` — 3단계 레이저 구체 투사체
- `BossHitbox.cs` — 보스 부위 히트박스(머리/몸통/팔다리 데미지 배율)
- `GameSfx.cs` — **임시** 효과음(파형을 코드로 합성) / `GameSfxOverrides.cs` — 진짜 클립으로 교체하는 지점

## 1. 플레이어 준비
1. `Resources/Player/source/Idle.fbx`를 Hierarchy로 드래그.
2. FBX Import Settings → Rig 탭 → **Animation Type = Humanoid** → Apply.
3. Player에 컴포넌트 추가:
   - **CharacterController** (Center Y ≈ 0.9, Height ≈ 1.8, Radius ≈ 0.3)
   - **WeaponHolder**
   - **PlayerController**
   - **PlayerShooter**

## 2. 총 부착 (WeaponHolder)
1. `Resources/Gun/source/assault_rifle.fbx`를 씬에 드래그.
2. WeaponHolder의 `Existing Weapon`에 씬의 assault_rifle 지정
   (또는 프리팹으로 만들어 `Weapon Prefab`에 지정).
3. `Hand Bone Name`은 기본값 `mixamorig:RightHand` 그대로.
4. Play 후 `Local Position/Euler/Scale`로 손 안 위치 미세조정.
5. 총 끝에 빈 GameObject `Muzzle`를 자식으로 만들어 총구에 배치.

## 3. 카메라 (ThirdPersonCamera)
1. **Main Camera**에 `ThirdPersonCamera` 추가.
2. `Target`에 Player 지정. `Pivot Height`는 캐릭터 어깨/머리 높이(≈1.5).
3. `Collision Mask`에서 Player 레이어는 제외(자기 자신에 막히지 않도록).

## 4. 발사 연결 (PlayerShooter)
- `Aim Camera` = Main Camera (비워두면 Camera.main 자동)
- `Muzzle Point` = 2-5에서 만든 Muzzle
- `Hit Mask`에서 Player 레이어 제외(자기 몸에 맞지 않도록)
- 이펙트는 선택: Muzzle Flash(ParticleSystem), Impact Prefab, Tracer(LineRenderer)

## 5. 조작
- 이동: WASD (**이동하면 항상 달린다** — 조준 중에만 걷기) / 점프: Space / 구르기: 이동 중 **Left Shift**
  - Shift는 달리기 전환이 아니라 **회피 전용**이다. 달리기가 상시가 되면서 비어 C에서 옮겨왔다.
  - 구르기는 `Roll Speed Up`(1.6배)로 재생되고, 클립의 `Roll Control Return`(0.7) 지점을 지나면
    **일어서는 뒷부분은 애니메이션만 마저 블렌드되고 조작은 즉시 돌아온다**.
    애니메이터도 롤에서 Run/Walk/Idle로 **직접** 빠져나가므로 블렌드가 두 번 겹치지 않는다.
  - 회피기이므로 애니메이터의 롤 진입은 **AnyState → Running Dive Roll**이다.
    Rifle Run에서만 걸어 두면 출발 동작(`Idle To Running`) 중에 누른 회피가 트리거로 대기하다
    뒤늦게 튀어, 정작 맞는 순간에는 구르지 못한다.
  - **기력은 롤 상태에 실제로 들어간 프레임에서 차감된다**(누른 시점이 아니다).
    구르는 중의 Shift 입력은 무시되고 트리거도 즉시 지워지므로,
    연타해도 구른 횟수와 기력 소모가 정확히 1:1로 맞는다.
- 조준: 우클릭(길게) / 발사: 좌클릭 / 재장전: R
  - **빠른 재장전**: 재장전 중 다시 **R**. 크로스헤어 아래 막대의 화살표가 푸른 구간을
    지날 때 누르면 즉시 완료된다(아래 [빠른 재장전](#빠른-재장전-액티브-리로드) 참고).
- 마우스: 카메라 회전(커서는 잠김)
- **타임 어소리티(G)**: 크로스헤어가 겨누는 대상을 과거의 나와 함께 사격(타임포스 소모).
  적을 스스로 찾지 않으므로 **겨눈 대상만** 친다. 사격 중에도 끊김 없이 쓸 수 있다.
  - 과거의 나는 반동을 잡아 주지 못한다 — 탄 퍼짐·반동이 **플레이어의 1.5배**
    (`Ghost Spread Scale`)로 적용돼 길게 쏠수록 총구가 들리고 탄이 벌어진다.
    빗나가면 그대로 빗나가므로, 협공만으로 표적을 계속 맞힐 수는 없다.
    수치는 플레이어의 총 그대로를 배율만 곱해 쓰므로 총을 바꾸면 함께 따라간다.
- **크로노 브레이크(T)**: 선택 창 없이 **즉시** 발동 — 지나온 길을 거꾸로 되감기며 5초 전 상태
  (위치·자세·체력·탄약)로 돌아간다. 월드(보스 패턴 등)도 함께 역재생된다.

두 능력에는 각각 **재사용 대기**가 있다 — 크로노 브레이크 10초 / 타임 어소리티 8초(발동 순간부터).

### 시간 능력 HUD

두 능력 모두 **타임포스 30**과 **과거의 나(고스트) 준비**가 있어야 발동한다. 타임포스는 시작값 0에
자동 충전이 없는 획득형이라, 조건을 못 채우면 키를 눌러도 아무 일이 없다. 그래서 좌하단에 상태를 띄운다.

- **능력 슬롯 2칸** (`T` 크로노 브레이크 / `G` 타임 어소리티) — 스탯 바 바로 위
  - `준비` = 지금 쓸 수 있음 / `3.4s` = 재사용 대기 남은 시간 /
    `TF -12` = 타임포스가 12 모자람 / `재충전` = 고스트가 아직 안 모임
  - 칩 배경의 채움 = 쿨다운 중에는 **쿨다운 진행**, 아니면 비용 대비 타임포스 충전 정도,
    **협공 사격 중에는 남은 사격 시간**(`발동 중`)
- **타임포스 바의 세로 눈금** = 비용 지점. 눈금을 넘어야 능력이 열린다.
- **실패 토스트** — 눌렀는데 발동하지 않으면 이유를 1.6초간 표시한다
  (`재사용 대기 3.4s` / `과거의 나 재충전 중` / `겨누는 대상이 없다` / `타임포스 부족 — 30 필요`)

> 머리에 맞히면 타임포스를 **+3** 받는다(`Time Force On Weak Point Hit`). 정확히 쏠수록
> 시간 능력이 빨리 돌아오게 해서, 부위 판정과 자원 순환을 하나로 묶은 장치다.

### 게임 오버 / 재시작

체력이 0이 되면 **`Dying.fbx` 쓰러지는 모션**이 재생되고, 화면이 어두워지며
**GAME OVER / RESTART?** 가 뜬다. **R** 을 누르면 현재 씬을 다시 불러 처음부터 시작한다.

- 사망 모션은 애니메이터의 **AnyState → Dying** 전환이라 어떤 자세(달리기·구르기·재장전 중)에서
  죽어도 재생된다. 루프를 끄고 나가는 전환을 두지 않아 **쓰러진 마지막 자세로 멈춘다.**
- 사망 시 상체 레이어(소총 파지)를 내린다 — 안 그러면 몸은 넘어가는데 상체만 총을 든 채 서 있다.
- 접지 보정·조준 보정·시선 IK도 함께 끈다. 쓰러진 몸에 걸면 다리가 땅으로 끌려가고
  시체의 가슴이 카메라를 따라 비틀린다.

- 사망 후에는 이동·사격·시간 능력이 모두 잠긴다. R은 재장전이 아니라 **재시작 전용**이 된다.
- 커서 잠금이 풀려 창 밖으로 뺄 수 있다(재시작하면 카메라가 다시 잠근다).
- 재시작 전에 `TimeShiftController.ResetGlobalState()`로 씬을 넘어 남는 static 상태를 비운다.
  이걸 빼먹으면 **시간역행 도중에 죽었을 때** `RewindActive`가 true인 채로 새 씬이 시작돼
  조준·발사가 영영 잠긴다.
- 씬은 Build Settings에 등록돼 있어야 한다(현재 `SampleScene` 등록 완료).

## 6. 발사 테스트
- Cube 하나 만들고 `TargetDummy` 추가 → 쏘면 빨갛게 깜빡이고 체력 0에 파괴됨.

## 7. (선택) 애니메이션 연결
Animator Controller를 만들어 아래 파라미터를 쓰면 스크립트가 자동 갱신한다:
- `Die` (Trigger) — 사망(AnyState에서 걸려 어떤 자세에서든 재생)
- `Speed` (Float) — 이동 블렌드용
- `IsAiming` (Bool) — 조준 상태
- `Fire` (Trigger) — 발사 순간

Mixamo 클립 매핑 예:
- Idle/걷기 → Blend Tree (Speed)
- 조준 대기 → `Rifle Aiming Idle`
- 발사 → `Firing Rifle` / `Aiming Firing Rifle`

각 애니메이션 FBX도 Rig = Humanoid로 임포트해야 아바타가 공유된다.
Animator가 없어도 이동/조준/발사는 정상 동작한다.

## 8. 보스 몬스터 (AlienMonster)

메뉴 **Tools/TPS/Setup Boss (AlienMonster)** 한 번이면 배치·연결이 끝난다.
(프리팹 배치 → 플레이어 키의 1.6배로 크기 보정 → CharacterController 실측 →
`BossController`/`BossRig`/`TimeRewindable` 부착 → `Boss.controller` 생성/연결)

부위별 데미지를 쓰려면 이어서 **Tools/TPS/Setup Boss Hitboxes (부위별 데미지)** 를 한 번 실행한다
(아래 [부위별 데미지](#부위별-데미지-히트박스) 참고).

### 등장 컷신

게임을 시작하면 보스는 **은신한 채로** 제자리에 서 있고, 카메라가 그 빈 자리를 천천히 돌며 비춘다.
아무것도 없는 자리를 먼저 보여준 뒤(`Intro Hold Time`) 섬광과 함께 모습을 드러내며 포효한다
(`dragon-studio-alien-sounds-463202`). 그 다음 카메라가 플레이어에게 돌아오고 전투가 시작된다.

- 컷신 동안 **이동·시점·사격·시간 능력이 모두 잠긴다**(`BossController.CutsceneActive`).
  카메라가 보스를 보고 있는데 조작이 열려 있으면 화면 밖에서 움직이게 되기 때문이다.
- 보스 체력 바와 전투 음악도 컷신이 끝나야 나온다.
- 컷신이 어떤 이유로든 중간에 끊겨도(보스 비활성화·파괴·사망) 잠금은 반드시 풀린다.
- `Play Intro`를 끄면 예전처럼 시작하자마자 바로 전투가 시작된다.
- 연출 각도/거리는 `ThirdPersonCamera`의 **컷신 카메라** 항목에서 조절한다
  (`Cinematic Distance` / `Cinematic Height` / `Cinematic Orbit Speed`).

### 체력 단계 (패턴 해금)

체력이 깎일수록 쓰는 패턴이 늘고, 기존 패턴도 형태가 바뀐다.
경계값은 `Stage2 Health Ratio`(70%) / `Stage3 Health Ratio`(50%).

| | **1단계** (70%~) | **2단계** (~70%) | **3단계** (~50%) |
|---|---|---|---|
| 근접 | **1회** 할퀴기 | 3연타 | 3연타 |
| 원거리 | 조준 레이저 | 조준 레이저 | **레이저 구체 3연발** |
| 돌진 | — | 돌진 할퀴기 | 돌진 → **그대로 3연타** |
| 하늘 | — | **레이저 강우** | **구체 강우** |
| 텔레포트 | **접근만** | 충격파(둔화 + 레이저 낙하) | 충격파(둔화 + 구체 낙하) |

> 1단계에서 텔레포트가 아무것도 터뜨리지 않는 이유: 초반부터 둔화 + 낙하물이 겹치면
> 플레이어가 기본 패턴(할퀴기·레이저)을 익힐 틈이 없다. 2단계부터 압박이 시작된다.

체력 30%의 **분신 처형**은 단계와 별개로 1회 발동한다(3단계 안에서 일어난다).
그 패턴을 넘기면 **공중 처형**이 열려 이후 쿨다운마다 반복된다 — 사실상 마지막 국면이다.

### 행동 패턴
| 패턴 | 발동 조건 | 흐름 |
|---|---|---|
| 추격 | 항상 | **걷기만** 사용(달리기 모션 없음). 먼 거리는 텔레포트가 담당 |
| 근접 할퀴기 | `Melee Range` 안 | 1단계 1타 / 2단계부터 **연속 3타**(오른팔 → 왼팔 → 오른팔 마무리) |
| **돌진 할퀴기** | 2단계~, `Rush Min Range`~`Rush Max Range`(3.2~9m), 시야 확보 | 양팔을 뒤로 당기며 **바닥에 돌진 통로**가 그려짐 → 직선 돌진 → 양팔 X자 교차 (3단계는 이어서 3연타) |
| 레이저 | `Laser Min Range`~`Laser Range`, 시야 확보 | 왼팔을 뻗고 검지 끝에 빛이 맺힘 → 일렁임이 점점 빨라짐 → 발사 |
| **레이저 구체** | 3단계에서 위 레이저를 대체 | 같은 자세로 구체를 `Orb Burst Count`(3)발 연달아 던진다 — **날아오는 동안 계속 보인다** |
| **하늘 강우** | 2단계~, `Sky Rain Min Range` 밖 | 팔을 **하늘로** 들어 쏘아 올림 → 잠시 뒤 플레이어 주변으로 쏟아진다 |
| 텔레포트 | 발동 거리 밖에 `Teleport Delay` 이상 머물면 — **쿨다운 없음** | 번쩍이며 사라짐 → 등 뒤(65%)/정면에 등장 → (2단계~) **충격파** |
| **분신 처형** | 체력이 `Judgment Health Ratio`(30%) 이하로 떨어지는 순간 **1회** | 맵 밖 원주에 진짜 포함 10기 정렬 → 일제 충전 → 파훼 또는 일제 사격 |
| **공중 처형** | 분신 처형이 끝난 뒤부터(체력 30% 이하 유지 시), 쿨다운 18초 | 아레나 **한가운데 상공으로 텔레포트** → 내려다보며 구체 **10연발** → 공중에서 굳음 → 지상 복귀 |

> 텔레포트 자리는 반드시 **아레나 안쪽**이어야 한다(`ValidateSpot`). `ArenaWall`은 실제 콜라이더라
> 한 번 밖으로 나가면 걸어서 돌아올 수 없어 벽에 붙은 채 굳는다. 그래도 어떤 경로로든 밖에 남으면
> `TryPullInsideArena`가 안쪽 가장자리로 되돌리고 경고를 남긴다.

> 할퀴기는 팔이 정면을 지나는 순간 **발톱 자국(`BossFx.ClawSlash`)** 이 허공에 새겨진다.
> 자국의 반지름은 실제 판정 사거리와 같게 그리므로 **보이는 만큼 맞는다** —
> 사거리를 조절하면 이펙트 크기도 따라간다.

### 회피
- 레이저는 발사 **`Laser Lock Time`(기본 0.4초) 전에 조준이 고정**된다. 이때 예고선 위로
  **흰 경고선이 빠르게 깜빡이므로**, 그 순간 구르기(이동 중 `Shift`)로 옆으로 빠지면 피할 수 있다.
- 돌진은 예비동작 후반 40%에서 방향이 고정된다. 바닥에 그려진 **통로 폭 밖으로** 구르면 피하고,
  빗나간 보스는 지나친 자리에서 크게 미끄러지며 굳는다(반격 기회).
- 하늘에서 떨어지는 것(레이저 강우 · 구체 · 텔레포트 충격파)은 전부 같은 예고를 쓴다 —
  착탄 링 안쪽에서 **카운트다운 링이 중심으로 조여들고, 그 링이 닫히는 순간이 착탄**이다.
- 레이저 구체(3단계)는 발사 순간이 아니라 **날아오는 내내 보인다** — 예고를 읽는 게 아니라
  실제로 궤도를 보고 비켜야 한다. 대신 터지면 반경 전체가 피해라 살짝 스치는 회피로는 부족하다.
- **공중 처형** 동안 보스는 공중에 멈춰 있어 근접·돌진이 전부 봉인된다. 구체가 하나씩
  날아오므로 계속 자리를 옮기며 흘리고, **10발을 다 쏜 뒤 굳는 구간**에 올려다보고 쏘면 된다.
- 구르기 중에는 `PlayerStats`의 무적 프레임도 적용돼 근접 할퀴기도 흘릴 수 있다(타임포스 획득).

### 조정 포인트 (BossController 인스펙터)
- 거리/속도 수치는 모두 **사람 1.8m 기준**이며, 실제 캐릭터 키에 맞춰 런타임에 자동 환산된다.
- 난이도: `Melee Cooldown`, `Laser Cooldown`, `Laser Lock Time`(클수록 피하기 쉬움), `Max Health`
- 단계 경계: `Stage2/Stage3 Health Ratio`. 1단계 할퀴기 타수는 `Melee Hits Stage1`(1),
  2단계부터는 `Melee Combo Hits`(3)를 쓴다.
- 근접 사거리 `Melee Range`(1.7m). 판정 여유는 이 값의 1.1배까지만 인정한다.
- 하늘 강우: `Sky Rain Cooldown`(11초) / `Sky Rain Count`(7) / `Sky Rain Min Range`(코앞에서는 안 쓴다)
- 레이저 구체: `Orb Burst Count`(3) / `Orb Speed`(느릴수록 피하기 쉬움) / `Orb Radius`(폭발 반경)
- 공중 처형: `Aerial First Delay`(분신 처형 후 첫 발동까지 6초) / `Aerial Cooldown`(18초) /
  `Aerial Height`(**월드 미터 0.6** — 실제 바닥을 재서 그 위로 올린다. 다른 수치와 달리
  캐릭터 키에 비례시키지 않는다. 비례시키면 보스 키의 4배까지 올라가 화면 밖으로 나간다) /
  `Aerial Barrage Count`(10발) /
  `Aerial Barrage Interval`(0.26초) / `Aerial Recover`(다 쏘고 굳는 1.2초 = 반격 구간)
- 눈빛(상시 — 살아서 모습을 드러내고 있는 동안 늘 켜져 있고, 숨은 동안과 죽은 뒤에만 꺼진다):
  `Eye Glow Color`(보라). 위치를 맞추는 방법은 아래 "눈 위치 맞추기" 참고.
- 모션이 뚝뚝 끊기면 `BossRig`의 `Weight Blend Speed`(14)/`Dir Blend Speed`(1000)를 낮춘다.
  너무 낮추면 할퀴기 스윙이 늘어져 타격감이 죽으므로 스윙 각속도(약 800도/초)보다는 크게 둔다.
- 돌진: `Rush Cooldown`(7초) / `Rush Windup`(예비동작이 길수록 반응하기 쉬움) /
  `Rush Radius`(받힘 판정 = 바닥 통로 폭) / `Rush Recover`(빗나가면 ×1.35로 더 오래 굳는다).
  Scene 뷰 기즈모에 **노란 원 두 개**로 발동 거리대가 보인다.
- 텔레포트 빈도: `Teleport Distance`(작을수록 자주 붙는다) / `Teleport Delay`
  - 실제 발동 거리 = `min(Teleport Distance, 아레나 반지름 × Teleport Arena Ratio)`.
    좁은 아레나에서 발동 거리가 맵보다 넓어 **텔레포트가 아예 안 나오는 것**을 막는다.
    (레이저를 쏠 거리대는 남기도록 `Laser Min Range`의 1.6배 아래로는 내려가지 않는다)
- 레이저 굵기는 `BossFx.Beam`의 `CoreWidth`/`GlowWidth` 상수로 조절(판정 반경은 `Laser Radius`)
- 연출: `Boss Color`(레이저·텔레포트 공통 색), `Melee Windup`(예비동작이 길수록 반응하기 쉬움)

### 참고
- 공격 전용 클립이 없어 팔 동작은 `BossRig`가 휴머노이드 본을 직접 돌려 만든다(리그 무관).
- `TimeRewindable`이 붙어 있어 시간역행 시 보스의 위치와 체력이 함께 과거로 돌아간다.
- 보스 체력은 화면 상단 중앙 바(HudUI)로 표시된다.

### 눈 위치 맞추기

보스를 선택하면 Scene 뷰에 **눈 자리가 보라색 원 두 개**로 그려진다(재생하지 않아도 보인다).
그 옆의 옅은 선은 **머리 축**(머리 본 → 정수리)이다 — 눈이 얹히는 기준 방향.

맞추는 방법은 두 가지다.

**1) 오브젝트로 (권장)** — 메뉴 **Tools/TPS/보스 눈 앵커 만들기**
머리 본 아래에 `EyeAnchor_L` / `EyeAnchor_R`을 만들고 `BossController`에 자동으로 연결한다.
이후에는 **씬 뷰에서 끌어다 놓으면** 끝이고, 앵커 오브젝트를 **키우면 눈도 같이 커진다**
(`localScale.x`가 크기 배율). 두 번 실행해도 오브젝트가 늘어나지 않고 제자리로 되돌아간다.

**2) 숫자로** — `Eye Glow Offset` / `Eye Glow Radius`
앵커를 비워 두면 이 값으로 계산한다. 단위는 미터가 아니라 **머리 길이(머리 본→정수리)에 대한 비율**이다.
`x`=좌우 간격(중심에서 한쪽), `y`=머리 축 방향 위, `z`=얼굴 앞. 비율이라 모델 크기가 바뀌어도 그대로 맞는다.

> '위'를 몸통이 아니라 **머리 축**으로 잡는 이유: 이 보스는 머리를 앞으로 **37도**쯤 내밀고 있다
> (`Head`→`HeadTop_End` 본 오프셋이 위 0.2275 / 앞 0.1714). 몸통의 위쪽을 기준으로 눈을 얹으면
> 얼굴이 아니라 뒤통수 위에 뜬다. '앞'은 그 축에 수직으로 세운 몸통 정면이라 얼굴 면을 따라간다.

눈은 **깊이 판정을 살려** 그리므로 뒤에서 보면 머리에 가려진다 — 정면으로 마주 봤을 때만 빛난다.
앞으로 너무 많이 빼면 얼굴에서 떠 보이고, 덜 빼면 머리 속에 묻혀 안 보인다. 이 둘 사이를 찾으면 된다.

### 부위별 데미지 (히트박스)

메뉴 **Tools/TPS/Setup Boss Hitboxes (부위별 데미지)** 한 번이면 끝난다.
휴머노이드 본을 따라 부위 히트박스를 만들고 레이어·마스크까지 전부 잡아 준다.

| 부위 | 데미지 | 타임포스 | 콜라이더 |
|---|---|---|---|
| 머리 | **×2.5** | **+3** | 구(머리 본 → 머리끝 본 실측) |
| 가슴 / 복부 | ×1 | +1 | 캡슐(Spine→Neck, Hips→Spine) — 반지름은 **허리~목 길이** 기준 |
| 팔·다리(위/아래) | ×0.6 | +1 | 캡슐(마디마다 하나) |
| 손 / 발 | ×0.6 | +1 | 구(마디 캡슐이 손목·발목에서 끝나 생기는 빈틈 메우기) |

약점(머리)에 맞으면 **탄착 이펙트도 달라진다** — `Crit Impact Color`(기본 노란빛)로 1.7배 크게 터지고
입자가 2.2배 튀며 점광원이 한 번 번쩍인다. 협공(과거의 나)이 머리를 맞혀도 같은 규칙이 적용된다
(고스트 색을 유지한 채 뜨거운 쪽으로 섞은 색). 몸통에 맞았을 때와 화면에서 즉시 구분된다.

> 몸통 반지름을 CharacterController에서 뽑지 않는 이유: 그 값은 **팔을 벌린 폭**(렌더러 바운즈)에서
> 나온 것이라 몸통에 쓰면 지나치게 뚱뚱해져 **머리 히트박스를 통째로 삼킨다**(= 헤드샷이 영영 안 터진다).
> 가슴 반지름에는 "머리 구가 반드시 밖으로 튀어나오도록" 하는 클램프가 한 겹 더 걸려 있다.

배율은 각 `Hitbox_*` 오브젝트의 **BossHitbox → Damage Multiplier**에서 바꾼다(0이면 그 부위는 무효).
크기가 안 맞으면 콜라이더를 직접 늘리면 되고, 메뉴를 다시 실행하면 **배율은 그대로 둔 채 크기·위치만**
다시 계산한다(이미 프리팹에 적용한 뒤에도 안전하다 — 프리팹 인스턴스의 자식은 삭제할 수 없기 때문).
프리팹에도 반영하려면 씬의 Boss 우클릭 → **Prefab → Apply All**.

**동작 원리** — 사격/협공 코드는 모두 `hit.collider.GetComponentInParent<IDamageable>()`로 대상을 찾는다.
이 함수는 *맞은 콜라이더의 오브젝트부터* 위로 올라가므로, 콜라이더와 같은 오브젝트에 있는
`BossHitbox`가 `BossController`보다 먼저 잡힌다 → 배율을 곱해 본체로 넘긴다.
사격 쪽 코드는 고칠 것이 없다.

**레이어 두 개**가 함께 만들어진다(도구가 자동 처리).

- `BossHitbox` — 히트박스 전용. 충돌 매트릭스를 전부 꺼서 **아무도 밀지 않는다**.
  레이캐스트는 매트릭스와 무관하므로 총알 판정은 그대로 받는다.
  카메라 충돌 / 보스 장애물 마스크에서도 빠진다.
- `BossBody` — 보스 본체(CharacterController). **사격·조준 마스크에서 제외**된다.
  몸통 캡슐이 총알을 먼저 막으면 부위 판정이 영영 오지 않기 때문이다.
  이동·중력·벽 충돌은 그대로다.

> 협공(G)은 겨눈 부위를 계속 쏘므로, 머리를 겨눠 발동하면 지원 사격도 전부 ×2.5로 들어간다.
> 분신은 콜라이더가 없는 껍데기라 히트박스도 복제되지 않는다(예전과 동일).
> 히트박스가 없는 보스는 예전처럼 몸 전체가 같은 피해를 받는다.

### 근접 연타 (할퀴기 콤보)

`Melee Combo Hits`(3회)만큼 **양팔을 번갈아** 휘두른다. 첫 타만 `Melee Windup`(0.5초)으로 크게 당기고,
이후는 `Melee Combo Interval`(0.16초)로 짧게 이어져 연타로 보인다.
마지막 타는 `Melee Finisher Scale`(1.6배)만큼 궤적이 크고 피해·사거리·전진이 늘어난다.

- 한 대의 피해 = `Melee Damage` × `Melee Combo Damage Scale`(0.55).
  3연타 전부 맞으면 원래 1타보다 아프지만, **각 타를 따로 회피**할 수 있다.
- 이전 타의 팔은 다음 예비동작 동안 가중치를 빼며 내려가므로 동작이 끊겨 보이지 않는다.
- 궤적(트레일)은 양손 손가락 끝 모두에 붙어 있다.

### 텔레포트 충격파 (둔화 + 운석)

보스가 등장하는 순간 두 가지가 함께 터진다.

- **이동 둔화**: `Teleport Slow Factor`(0.7 = 30% 감소)를 `Teleport Slow Time`(1.5초) 동안.
  구르기에는 적용되지 않으므로, 둔해진 상태에서도 회피 수단은 남아 있다.
- **운석**: 플레이어 주변에 예고가 뜨고 `Meteor Fall Time`(1.1초) 뒤 떨어진다.
  `Meteor Count`(4발) × `Meteor Damage`(16), 착탄 반경 `Meteor Radius` 안이면 피격.
  텔레포트에 쿨다운이 없으므로 운석 쪽에 `Meteor Cooldown`(4초)을 둬서 계속 쏟아지지 않게 했다.
  - 예고는 **3중**이다 — 착탄 반경 링(깜빡임이 점점 빨라짐) + **중심으로 조여드는 카운트다운 링**
    (닫히는 순간이 착탄) + 착탄점 위로 선 **빛기둥**(고개를 들지 않아도 어디가 위험한지 보인다).
  - 착탄하면 충격파 링이 반경 2.6배까지 퍼지며 사라진다(어디까지 위험했는지 남는 잔상).

> 둔화 + 운석 조합이 "텔레포트로 붙는다"를 실제 압박으로 만든다. 너무 아프면
> `Meteor Damage`를 낮추거나 `Meteor Fall Time`을 늘려(예고를 길게) 난이도를 조절한다.

### 분신 처형 (체력 30% 전용 패턴)

보스 체력이 30% 밑으로 떨어지는 순간 **한 번만** 발동한다.

1. 진짜 보스가 사라지고, **아레나 밖 원주에 진짜 포함 10기**가 같은 간격으로 늘어선다.
   (`Judgment Clone Count` + 1기 / 반지름 = 아레나 반지름 × `Judgment Ring Scale`)
2. 전원이 플레이어를 겨누고 레이저를 충전한다. **진짜만 충전 색이 다르다**
   (`Judgment Real Color` 주황 vs 분신은 `Boss Color` 보라).
3. `Judgment Charge Time`(6초) 안에 진짜에게 **`Judgment Break Hits`(45)발을 명중**시켜야 파훼된다.
   - **협공(G)과 일반 사격이 함께** 이 횟수를 채운다. 협공 한 발로는 끝나지 않으므로,
     진짜를 찾아낸 뒤에도 남은 시간 동안 계속 퍼부어야 한다.
     (협공은 3초 × 초당 8발 = 최대 24발, 나머지는 플레이어의 사격 몫)
   - **이 패턴 동안에는 체력이 깎이지 않는다.** 명중 횟수만 쌓이고, 45발을 채우는 순간
     `Judgment Break Damage`(120)가 한 번에 들어간다. 진행도는 HUD의 **파훼** 게이지로 보인다.
   - 잘못 겨눠 분신에게 협공하면 타임포스만 소모된다(분신은 피해를 받지 않는 표적).
   - **패턴이 시작되기 전부터 날아오던 협공은 진행도를 채우지 못한다.** 협공은 초당 여러 발이라
     그대로 두면 체력을 30%로 만든 그 협공의 남은 탄이 진행도를 공짜로 채워 버린다.
     패턴 진입 시 진행 중인 협공은 중단되고(고스트 재충전 페널티는 없음), 새로 겨눠 발동해야 한다.
   - 파훼 성공 시 분신이 모두 소멸하고 보스가 `Judgment Stun Time` 동안 무방비로 굳는다(반격 기회).
4. 실패하면 10기가 `Judgment Volley Stagger`(0.12초) 간격으로 차례차례 발사한다.
   구르기 무적으로 전부 흘릴 수 없도록 벌려 두었으므로 사실상 사망한다.

> 분신은 보스 모델을 복제해 스크립트와 콜라이더를 전부 떼어낸 껍데기(`BossClone`)다.
> 비활성 컨테이너 안에서 복제하므로 원본 스크립트의 Awake가 돌지 않는다.
> 화면 상단의 경고 · 파훼 진행도 · 남은 시간 바는 `HudUI`가 그린다.
>
> 분신에는 콜라이더가 없어 총알이 그냥 통과한다 — 탄착 이펙트가 튀는 쪽이 진짜라는 뜻이다.
> 색으로만 찾게 하고 싶다면 분신에도 히트박스를 남기면 되지만, 그때는 분신이 제 손끝에서
> 나가는 레이저를 제 팔로 막지 않도록 `BossClone.Fire`의 레이캐스트에 자기 몸 제외가 필요하다.

## 9. 사운드

`GameSfx.cs`가 종류마다 다음 순서로 소리를 정한다.

1. 씬의 `GameSfxOverrides`로 직접 지정한 클립
2. `Assets/Resources/Sounds/`에 있는 **진짜 음원**(`GameSfx.ResourceName`에 적힌 이름으로 자동 로드)
3. 없으면 **파형을 코드로 합성**한 임시 사운드

덕분에 음원을 구한 종류만 파일을 넣으면 되고, 나머지는 합성음으로 계속 굴러간다.
씬에 아무것도 붙일 필요가 없으며, 첫 재생 때 준비되고 16개짜리 보이스 풀을 돌려쓴다.

### 남은 종류를 진짜 사운드로 교체하기

- **파일로**: 음원을 `Assets/Resources/Sounds/`에 넣고 `GameSfx.ResourceName`에 [종류 → 파일 이름]을 한 줄 추가한다.
  - 여러 변형이 한 파일에 이어 붙은 팩(`... 9 variations` 등)은 `GameSfx.MaxLength`에 재생 길이를
    적어 앞의 한 발만 쓴다. 안 그러면 한 번 맞을 때마다 변형이 줄줄이 다 울린다.
    끝은 0.08초 페이드로 내려가므로 '딱' 하고 끊기지 않는다.
- **씬에서**: 아무 오브젝트(예: `GameHUD`)에 **`GameSfxOverrides`** 를 붙이고 목록에 [종류 + AudioClip]을 넣는다.
  코드를 건드리지 않으며 파일 자동 로드보다 우선한다.

전체 음량은 `GameSfxOverrides`의 `Master Volume`(플레이 중에도 즉시 반영)에서 조절한다.

> 종류를 추가하려면 `Sfx` enum에 항목을 넣고 `GameSfx.Build`/`DefaultVolume`에 정의를 더한다.
> 발사음처럼 초당 여러 번 울리는 소리는 `DefaultVolume`에서 작게 잡아 두었다.

## 10. 원형 아레나 낙하 방지

메뉴 **Tools/TPS/Build Arena Wall (낙하 방지)** — 발판을 실측해 보이지 않는 벽을 세운다.

- 중심에서 32방향으로 바닥을 아래로 훑어 **발판이 끊기는 반지름**을 찾는다.
  (스테이지 모델의 바운즈는 배경 구조물까지 포함할 수 있어 쓰지 않는다)
- 그 둘레에 `ArenaWall`이 박스 콜라이더 36조각을 원형으로 배치한다. 렌더러가 없어 보이지 않고,
  CharacterController가 막히므로 **플레이어와 보스 모두** 밖으로 나가지 못한다.
- 벽은 전용 레이어(`ArenaWall`)에 올라가며, 카메라 충돌 / 사격 / 조준 / 보스 레이저 마스크에서 자동 제외된다.
  (보이지 않는 벽에 총알이 맞거나 카메라가 튕기는 것 방지)

크기가 안 맞으면 씬의 `ArenaWall` 인스펙터에서 `Radius`/`Height`를 고치고
**우클릭 → 벽 다시 만들기**. 선택하면 초록색 원으로 범위가 표시된다.

> 아레나 오브젝트에 Collider가 없으면 측정에 실패한다(FBX 임포터의 Generate Colliders 확인).

### 크로노 브레이크와 보스 패턴

되감기는 위치·회전·체력만 되돌리는 것이 아니라 **보스의 패턴 쿨다운까지 함께 되돌린다**
(`BossController.OnRewoundTo`). 이게 없으면 보스는 "과거 자리에 과거 체력으로 서서
현재 패턴을 이어가는" 상태가 되어, 되감기 전과 다른 공격이 나온다.

- 쿨다운은 **절대 시각이 아니라 '그때 남아 있던 시간'** 으로 되돌린다.
  되감는 동안에도 `Time.time`은 계속 흘렀기 때문에, 과거의 "다음 발동 시각"을 그대로 넣으면
  이미 지나가 버려 모든 패턴이 즉시 사용 가능해진다.
- 분신 처형 여부(`_judgmentDone`)와 텔레포트 대기 누적(`_farTimer`)도 함께 되돌린다.
- 되감긴 뒤의 기록은 '오지 않은 미래'라 버린다.

> 되돌릴 상태가 더 있는 컴포넌트는 `IRewindTimeAware`를 구현하면 된다 —
> `TimeRewindable`이 되감기가 끝난 시점의 **과거 시각**을 넘겨준다.

## 11. 맵이 어두울 때

메뉴 **Tools/TPS/맵 밝기/권장값 적용** 한 번이면 대개 해결된다.
더 필요하면 **밝게 (+)** / **어둡게 (−)** 로 단계 조절, 지금 상태가 궁금하면 **진단**.

화면을 어둡게 만드는 곳은 한 군데가 아니라서, 이 도구는 네 가지를 **같이** 움직인다.

| 무엇 | 하는 일 | 이 씬의 값 → 권장값 |
|---|---|---|
| **비네트** | 화면 **가장자리**를 검게 덮는다 | **1.00(최대)** → 0.30 |
| 환경광(Trilight) | 직사광이 닿지 않는 면의 밝기 = 맵의 그늘 | 0.386 → 0.60 (하늘 기준) |
| Directional Light | 전체 기본 밝기 (색=분위기라 안 건드린다) | 세기 2.0 → 2.6 |
| 안개(지수제곱) | 먼 배경을 안개색으로 덮는다 | 밀도 0.09 → 0.05 |

> **환경광만 올려서는 해결되지 않는다.** 이 씬은 이미 환경광이 기본값(0.135)의 세 배 가까이
> 올라가 있었는데도 어두웠다. 비네트가 **최대치 1.0**이라 가장자리는 무엇을 해도 검게 남기
> 때문이다. TPS는 화면 가장자리에서 적이 들어오므로 이 값이 높으면 게임플레이에도 손해다.

비네트 값은 씬이 아니라 **Volume 프로파일 에셋**(`Settings/SampleSceneProfile.asset`)에 들어 있다.
도구가 에셋 저장까지 해 주므로 따로 저장할 필요는 없다.

네온 간판과 블룸이 이 맵의 인상이라, 권장값은 **바닥을 들어 올리되 네온을 죽이지 않는** 선에서 잡았다.
전부 되돌리려면 실행 직후 **Ctrl+Z**(한 단계로 묶여 있다).

## 12. 맵에 끼는 현상

`CharacterUnstick`(플레이어·보스 공용)이 매 프레임 겹친 깊이를 재서 밀어낸다.
CharacterController는 **스스로 겹침을 풀지 못하기 때문이다** — `Move()`는 이동을 막을 뿐이라
한 번 벽 안으로 들어가면 어느 방향으로도 나오지 못한다.

여기에 두 겹의 대비를 더 뒀다.

**1) 쐐기 처리** — 마주 보는 두 면(계단 옆면과 벽, 벽 이음매) 사이에 박히면 밀어내는 방향이
서로 상쇄돼 합이 0에 가까워진다. 그러면 "겹쳐 있는데 어디로도 못 빠지는" 상태가 유지된다.
합이 가장 깊은 겹침의 절반보다 작으면 **가장 깊이 박힌 쪽으로만** 뺀다(가장 얕게 나오는 길).

**2) 끼임 감시 → 탈출** (`Stuck Escape Time`, 기본 0.5초)
움직이려는데 못 움직인 시간이 쌓이면 확인 후 빼낸다. 위로 먼저, 그다음 수평 8방향을
**아레나 안쪽에 가까운 순서로** 훑고, 후보마다 **발밑에 바닥이 있는지** 확인한다
(끼임을 푸는 대신 허공에 떨어뜨리지 않도록).

> **"못 움직인다"만으로는 발동하지 않는다.** 벽에 대고 걸어도 똑같기 때문이다.
> 그 시간 동안 ①실제로 지오메트리에 파묻혀 있었거나 ②수평 여덟 방향이 전부 막혔을 때만
> 끼임으로 인정한다. 이 문턱이 없으면 벽을 향해 걷고 있을 뿐인데 몸이 옆으로 순간이동한다.

빠져나오면 **어느 콜라이더에 끼었는지 Console에 남는다.** 같은 자리에서 반복되면 그 이름이
원인이다 — `Seg_NN`이면 아레나 낙하 방지 벽이므로 **Tools/TPS/Build Arena Wall** 을 다시
실행하고, 맵 구조물 이름이면 그 조각의 콜라이더가 문제다.

보스는 이와 별개로 제자리걸음이 `Stuck Teleport Time` 이상 이어지면 텔레포트로 빠져나온다.

## 13. 패턴이 맵 밖에서 나올 때

보스가 아레나 밖으로 나가면 벽(`ArenaWall`, 실제 콜라이더)에 막혀 **스스로 돌아오지 못한다** —
그 한 번이 곧 전투 정지다. 그래서 안팎 판정을 두 군데로 모았다.

**1) 순간이동은 전부 `WarpTo` 한 곳을 지난다.** 여기서 아레나 밖이면 안쪽으로 당기고
경고를 남긴다(어느 패턴이 나가려 했는지 `패턴=` 으로 찍힌다). 패턴마다 자리를 따로
계산하다 보면 한 군데씩 빠뜨리게 되므로, 길목을 하나로 막았다.

**2) 안팎 판정은 `ArenaWall`이 로컬 좌표에서 한다** (`Contains` / `ClampedInside`).
벽 오브젝트에 축마다 다른 스케일이 걸려 있으면 월드에서는 원이 아니라 **타원**이 되는데,
월드 거리와 `Radius`를 그대로 비교하면 짧은 축 쪽에서 벽 너머를 '안'으로 인정해 버린다.
(이 씬의 벽은 실제로 x 0.96 / z 0.91로 눌려 있다)

같은 판정을 낙하물 착탄 지점과 분신 처형의 원 배치도 함께 쓴다.
분신은 **배치 전에** 당긴다 — 진짜만 나중에 당겨지면 반지름이 어긋나 정답이 드러난다.

### 공중 처형이 건물 위로 뜨던 문제

`TryFindFloor`는 기준 높이보다 **한 몸 높이까지 올라온 면도 발판으로 인정한다**(단·턱 위로
올려놓는 정상 동작). 그래서 이미 올라간 y를 기준으로 부르면 아레나 한가운데 구조물의
지붕을 바닥으로 잡고, 거기에 `Aerial Height`를 또 더해 보스가 맵 밖(건물 위)에 떴다.

바닥은 반드시 **보스가 서 있는 높이**를 기준으로 잰다(`TryFindFloorUnderBoss`).
`ResolveJudgmentRing`이 돌려주는 y는 분신이 뜰 *천장 근처* 높이이므로 바닥 탐색의 기준이 될 수 없다.

## 14. 빠른 재장전 (액티브 리로드)

재장전을 시작하면 크로스헤어 **바로 아래**에 막대가 뜬다. 화살표가 막대 위를 훑고
지나가고, 그 위 어딘가에 **푸른색 성공 구간**이 있다. 화살표가 그 구간 안에 있을 때
**R**을 다시 누르면 재장전이 **즉시** 끝난다.

- **성공 구간의 자리는 재장전마다 무작위**다. 고정되면 화면을 보지 않고 박자만 외워
  누르게 되고, 그러면 미니게임이 아니라 그냥 단축키가 된다.
- **기회는 재장전당 한 번.** 실패해도 벌칙(재장전 지연)은 없지만 기회가 사라지므로,
  연타로 긁어 맞히는 것이 최선의 전략이 되지 않는다 — 화살표를 보고 눌러야 한다.
- 읽는 법: 화살표가 구간에 들어오면 **밝아진다**(= 지금 눌러라). 성공하면 구간이 밝게 터지고,
  놓치면 회색으로 죽는다. 기회를 쓰고 나면 화살표가 흐려진다.
- 소리로도 갈린다 — 성공은 재장전음이 높게, 실패는 낮고 작게 울린다.
- **남은 시간은 화살표가 아니라 바탕이 차오르는 것으로 읽는다.** 화살표는 왕복하므로
  그 위치로는 재장전이 얼마나 남았는지 알 수 없기 때문이다.

### 보스 체력에 따라 어려워진다

보스 체력이 줄수록 **성공 구간이 좁아지고 화살표가 빨라진다.** 난이도는 재장전을
시작하는 순간 한 번만 정해 고정한다 — 매 프레임 다시 재면 재장전 도중 보스를 맞히는
순간 화살표 속도가 튄다.

| 보스 체력 | 구간 폭 | 화살표 | 구간을 지나는 시간 |
|---|---|---|---|
| 100% | 막대의 12% | 재장전 동안 1회 통과 | 약 **0.18초** |
| 0% 부근 | 막대의 9% | 1.35회 (35% 빠름) | 약 **0.10초** |

단계(70%/50%)로 끊지 않고 연속으로 둔다 — 한 대 때릴 때마다 아주 조금씩 조여드는 편이,
어느 순간 갑자기 어려워지는 것보다 압박이 자연스럽게 쌓인다.
보스가 없거나 죽었으면 가장 쉬운 값이다(전투가 아닐 때까지 어렵게 할 이유가 없다).

> 화살표가 1회를 넘겨 움직이면 **끝에 닿았을 때 되돌아온다**. 오른쪽 끝에서 왼쪽으로
> 순간이동시키면 그 순간을 눈이 놓치기 때문이다. 되돌아오는 길에 구간을 한 번 더 지나므로,
> 첫 통과를 놓쳐도 늦게 한 번 더 노려볼 수 있다(기회는 여전히 한 번뿐이다).

### 조정 (PlayerShooter 인스펙터)

| 항목 | 뜻 | 기본값 |
|---|---|---|
| `Active Reload Enabled` | 끄면 예전처럼 R이 재장전 중엔 아무 일도 안 한다 | 켜짐 |
| `Active Reload Window` | 성공 구간의 폭(막대 길이 대비) — 보스 **만피** | 0.12 |
| `Active Reload Window Min` | 성공 구간의 폭 — 보스 **빈사** | 0.09 |
| `Active Reload Sweeps` | 재장전 동안 막대를 가로지르는 횟수 — 보스 **만피** | 1.0 |
| `Active Reload Sweeps Max` | 가로지르는 횟수 — 보스 **빈사** | 1.35 |
| `Active Reload Range` | 구간이 놓일 수 있는 범위(막대 위 0~1) | 0.28 ~ 0.86 |

> 범위의 **앞을 비워 두는 이유**: 재장전이 시작되자마자 지나가면 반응할 시간이 없다.
> **뒤를 비워 두는 이유**: 끝에 붙으면 성공해도 아낀 시간이 없어 의미가 없다.

**구간 폭과 속도는 함께 봐야 한다.** 실제 난이도는 구간을 지나는 시간이고, 그 값은
`구간 폭 × 재장전 시간 ÷ 가로지르는 횟수`다. 속도를 올리면 폭을 그대로 둬도 어려워지므로,
둘을 동시에 크게 조이면 순식간에 불가능해진다. 0.10초 아래로는 내려가지 않게 두는 것이 좋다.

막대 크기·위치는 `HudUI.BuildReloadBar`의 `W`/`H`와 `PlaceCentered(..., -118f, ...)`에서 바꾼다.
탄약 표시가 있는 우하단은 후보가 아니다 — 성공 구간은 0.1~0.2초쯤 지나가므로,
시선을 화면 구석까지 옮겨야 하면 반응할 수가 없다.

> 성공 시 **재장전 모션도 함께 끊는다**. 발사 조건이 모션 재생 여부도 보고 있어서,
> 탄만 채우고 모션을 두면 탄은 찼는데 쏘지 못하는 상태가 되어 아낀 시간이 그대로 사라진다.

## 15. HUD의 SF 스타일

에셋 없이 코드로 만드는 HUD라, 필요한 모양은 전부 `HudUI`가 직접 굽는다(`Bake`).
전부 static 캐시라 씬을 다시 열어도 한 번만 만든다.

| 부품 | 쓰이는 곳 |
|---|---|
| **모서리 깎은 판**(속 채움 / 테두리) | 패널·게이지 홈·능력 슬롯·보스 바·재장전 막대·게임오버 판 |
| **육각형** | 능력 슬롯의 키 배지(T / G) |
| **사선 빗금**(타일) | 게이지의 빈 구간 — '비었다'가 질감으로 읽힌다 |
| **주사선**(타일) | 패널 위에 아주 옅게(알파 0.05) |
| **모서리 꺾쇠**(ㄴ자) | 패널·탄약판·재장전 막대의 네 귀퉁이 |

이 중 인상을 가장 크게 바꾸는 건 **모서리 깎기** 하나다. "사각형만 있는 UI"가 심심해 보이는
가장 큰 이유는 모서리가 직각이기 때문이고, 그것만 바꿔도 화면이 통째로 장비 패널처럼 읽힌다.

그 밖에:
- 좌하단 패널을 **6초에 한 번** 밝은 선이 훑고 지나간다. 정지 화면에서도 '켜져 있는 장비'로
  보이게 하는 장치다. 주기를 길게 잡아야 '가끔 스캔한다'로 읽힌다 — 빠르면 눈이 계속 끌린다.
- 라벨은 자간을 벌린다(`Spaced`). 레거시 `Text`에 자간 기능이 없어 글자 사이에 공백을 끼운다.
- 우하단 탄약도 판 위에 올렸다. 글자만 떠 있으면 좌하단 패널과 짝이 맞지 않는다.

### 만질 때 주의할 두 가지

**1) 마스크를 씌운 판에는 바깥 장식을 달지 말 것.**
모서리를 깎아도 자식(채움·빗금·광택)은 여전히 직각이라 깎아낸 자리로 삐져나온다.
그래서 게이지·능력 슬롯·보스 바에는 `ClipToShape`(스텐실 마스크)를 씌웠다.
그 판의 자식은 **판 모양 밖이 전부 잘린다** — 보스 이름표가 막대 위로 나가므로,
보스 바는 투명한 껍데기를 하나 두고 이름표를 거기에 단다.

**2) 스프라이트 캐시에 `??=`를 쓰지 말 것.**
`??=`는 진짜 null만 보는데, Unity 오브젝트는 파괴된 뒤에도 '가짜 null'로 남는다 —
그러면 파괴된 스프라이트를 영영 돌려주게 된다. 반드시 Unity의 `!=`로 확인해야 한다.

9슬라이스 경계는 16px이라, 작은 부품에서는 컷이 상대적으로 너무 커 보인다.
`MakeAngled(..., cornerScale:)`을 올리면 그만큼 작아진다(게이지 1.9 / 재장전 막대 3.2).
경계 두 개의 합이 부품 높이를 넘으면 모양이 찌그러지므로, 높이가 작을수록 값을 올려야 한다.
